# SevaConnect — Your Trusted Local Service Partner

SevaConnect is a modern, production-grade local services marketplace connecting Indian households with verified, background-checked service professionals (Electricians, Plumbers, Cleaners, AC Technicians, Carpenters, Painters, etc.).

## Project Architecture

- **`frontend/`**: Vite + React 18 single-page application with Tailwind CSS, Lucide icons, and comprehensive portal architecture (Public, Customer, Service Provider, Admin).
- **`docs/`**: Frontend architecture, user flows, and state specifications.
